# 苹果设备与电量：统一设置与显式选择

日期：2026-10-06

## 用户确认的目标

采用一个总开关、仅苹果设备的勾选列表；勾选后加入现有蓝牙状态面板。取消独立的附近 BLE 用户入口，BLE 仅作为内部实现。设置说明需要提及 iPhone、iPad、Apple Watch，以及 USB 信任和无线读取要求。此前移除状态行“附近 BLE”副标题的修改保留。

本设计取代旧 nearby BLE 设计中通用厂商发现、独立 BLE 开关和独立可信移动设备电量开关的要求；现有普通已配对蓝牙设备功能不变。

## 用户界面

- 总开关：**显示苹果设备与电量**。移除原“显示附近 BLE 设备电量”和“iPhone 与 Apple Watch 电量”两个入口。
- 开关下说明：**选择 iPhone、iPad、Apple Watch 等苹果设备，将其加入蓝牙设备列表并显示可读取的电量。通过 USB 或 Wi-Fi 读取 iPhone、iPad 时，首次需用 USB 连接、解锁并点按“信任”；无线读取还需配置 Wi-Fi 同步。Apple Watch 可尝试通过已信任的配对 iPhone 读取。附近蓝牙读取不要求 USB 信任，电量可用性因设备而异。**
- 开启后展示“选择苹果设备”列表和“查找设备”按钮。已保存设备离线时仍可取消勾选。新发现设备默认不勾选，不自动收录附近所有苹果设备。
- 设置选择列表可注明“附近蓝牙”“USB / Wi-Fi”“通过 iPhone”等来源和必要的信任提示；面板行不出现 BLE 来源副标题。
- 列表延续已保存排序和隐藏控制。获选设备无电量时也能形成行；待读取、无法读取和不在附近保持区分，不将未知电量显示为 0%。

说明中的 USB 信任步骤依据 Apple 支持文档 <https://support.apple.com/en-ie/109054> 。Watch 的可读性是本项目现有 helper 的能力限制，不宣称所有型号都支持。iPad 须增加 helper 与模型测试后才能宣称路径支持；无法实机验证的部分明确记录。

## 发现、范围与身份

一个选择目录汇集附近蓝牙发现和现有可信设备 helper 的设备元数据。只允许有来源证据的苹果设备进入新增选择目录：附近广播中已识别的 Apple company ID / Continuity 候选，或可信读取路径的已验证 Apple 产品型号。不得用名称中含“iPhone”或“Apple”判断厂商或归属；Apple 广播也不证明归属或电量支持。

iPhone、iPad、Apple Watch 是重点对象。其他可识别苹果设备可作为候选，但此功能不新增其电量协议。AirPods 等已经通过正常配对列表显示的设备保留原路径，不因总开关被移除，也不创建可证明为同一身份的重复行。

保留 BLE UUID 与可信设备标识的独立命名空间；不能按相同名称合并选择、授予读取或覆盖连接状态。只有可靠身份关联才能合并来源；无法证明的同名行在设置中标明来源和稳定后缀，保持独立。设备标识变更须重新勾选。

发现阶段不得为未获选设备发起 BLE GATT、电池服务读取或 helper 电量查询。可信 helper 可进行必要的设备枚举/型号及伴随设备元数据发现，但不能用全量电量读取来填选择列表。发现 Apple Watch 若依赖连接到其配对 iPhone，提示该发现依赖；不因父设备被发现就自动选择父设备或所有手表。

## 电量读取与生命周期

总开关只控制此功能新增的设备目录、显示和读取。已有全局“显示蓝牙设备电量”开关继续控制电量显示与读取；关闭全局电量时，获选苹果设备仍显示但不启动电量读取。

所有新增设备的读取许可为：总开关开启、全局电量开启、设备获选、未隐藏、实际在面板可见视口内、对应路径可用。关闭、隐藏、取消勾选、折叠或滚动离开时撤销相应读取，取消排队/进行中的任务并拒绝迟到回调。

BLE 路径保留扫描周期、缓存、并发和连接超时限制。可信路径增加按获选 ID 限制的读取接口，避免当前全量读取所有手机和手表。选择一只 Watch 时，允许其配对 iPhone 的必要会话，但不顺带查询或发布该 iPhone 及其他未获选 Watch 的电量。

BLE 临时 GATT 连接仍不作为用户“已连接”状态。保留只读行，无连接/断开按钮。可信路径可用但 BLE 失败时，不覆盖该可信身份已成功取得的读数；无可靠关联时不跨 UUID/可信 ID 串用读数。来源失败提示仅影响相关路径，避免与另一行的成功电量形成全局矛盾提示。

## 设置持久化与迁移

新增统一总开关键和来源类型明确的持久化选择。新安装默认关闭、选择为空。首次迁移总开关取旧两个开关的逻辑 OR，随后旧键不再驱动功能。

保留可确认 Apple 厂商/型号的原 BLE 选择及其排序/隐藏偏好。其他厂商或未确认厂商的历史选择保留在迁移存档，不显示、不读取、不默认为苹果；可以重新发现并确认后由用户选择。旧可信设备开关仅迁移“功能开启”状态，不自动授予新发现可信设备的读取许可；提示用户在新列表中勾选。迁移幂等，重启不重新导入或复活已取消的选择。关闭总开关保留选择，下次开启恢复。

用户文案覆盖全部 12 个本地化目录并沿用现有术语。此变更不改变菜单栏/Dock 图标选项；若实现新增任何图标选项，必须同时更新菜单栏和 Dock。
