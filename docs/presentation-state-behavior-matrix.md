# Presentation Refactor Behavior Matrix

This is the pre-migration ownership map for the presentation-state refactor. It records current executable characterization, the behavior those tests pin, and the remaining regression targets. The matrix is intentionally specific to the current tests; a test file's existence does not count as coverage of every case in its topic.

`PresentationBaselineTests` adds shared stable inputs and pins the current Wi-Fi and volume buckets. It is a characterization baseline: the first run passes against the existing implementation. The fixture's Bluetooth output delegates to `SheetFixtures.bluetoothDevice` so test consumers share the same AirPods Pro identity and Bluetooth transport.
