# バージョン %VERSION%（ビルド %BUILD%）

## 今回のハイライト：Bluetooth オーディオ
- ポップオーバーの「Bluetooth」行がリアルタイムの状態を表示するようになりました。接続中のデバイス名に加え、AirPods では左右とケースのバッテリー残量も表示します。その他のデバイスは名前のみです。
- Bluetooth でオーディオを再生している間、中央のネットワークアイコンを対応するデバイスのアイコン（AirPods、ヘッドホン、スピーカーなど）に切り替えて青色で表示できます。音量ドットまたは円弧も青色になり、使用中の出力が一目で分かります。
- 新しく「設定 > Bluetooth」ページを追加：ネットワークアイコンの置き換え、Bluetooth 音量を青色にする、ネットワークエラーを優先する、Bluetooth のバッテリー残量を表示する、の各スイッチと、100%〜180% の Bluetooth アイコンサイズ。
- システム設定で名前を変更したデバイスが古い名前のまま表示される問題を修正しました。
- 概要とデバイスページを切り替えると Bluetooth のバッテリー残量が「利用できません」のままになる問題を修正しました。

## バッテリーの詳細
- ポップオーバーのバッテリー行をクリックすると専用ページが開き、電源アダプタの定格、残り時間、低電力モード、電圧、電流、サンプル時刻、充放電回数を確認できます。
- バッテリーの正味電力の推定値を追加：充電中は緑色で「充電（推定）」、放電中は「放電（推定）」と表示します。
- これらの値はベストエフォートの推定値であり、Mac 全体の消費電力ではありません。電源を切り替えた後、macOS が新しい値を報告するまで最大約 1 分かかることがあり、その間は「利用できません」ではなく「サンプリング中」と表示します。

## Wi-Fi の概要
- Wi-Fi 接続時、ポップオーバーはネットワーク名（SSID）をタイトルにし、その下に現在の周波数帯と電波強度を表示します（例：5 GHz / -52 dBm）。
- 取得できない測定値は 0 ではなく省略されます。Ethernet、オフライン、その他の非 Wi-Fi 経路では表示されません。

## アイコンの見方
- 新規インストールでは、初回起動時に「アイコンの見かた」ガイドが開きます。バッテリーの円弧、中央のネットワークアイコン、音量インジケータを選ぶとそれぞれの意味が分かります。音量の説明は現在のドット／円弧の設定に従います。
- ガイドにはよくある状態の組み合わせ一覧が含まれます：充電、低バッテリー、Ethernet、インターネットなしとミュート、低電力モードのホットスポット、弱い Wi-Fi と音量 25%、Wi-Fi オフ、Bluetooth ヘッドホン、AirPods、Wi-Fi と青色の音量。
- このバージョンへのアップデート、再起動、既存のインストールでは自動的に開きません。「設定」、「アプリアイコン」、「ガイドを開く」からいつでも開けます。

## 音量
- 新しい「ナチュラルスクロール」スイッチ：オンのときは、システムのナチュラルスクロール設定に関係なく、マウスやトラックパッドで上にスクロールすると音量が上がります。オフのときは音量がシステムのスクロール方向に従います。
- 新しい「調整範囲」の選択：パネルのどこでもスクロールするか、音量コントロール上だけでスクロールするかを選べます。
- オンにしても上スクロールで音量が下がる場合は、MOS、Scroll Reverser、LinearMouse などのスクロールユーティリティがイベントを反転しています。そのアプリの例外／無視リストに Status Trio を追加してください。

## 設定と外観
- 音量スタイル（ドットまたは円弧）、アイコンの配置、外環の線の太さがビジュアルカード選択になりました。選択項目は同心円で示され、カード内で結果をプレビューできます。
- 新しい「外環の線の太さ」設定：細い、標準、太い。バッテリーの外環、音量の円弧、音量ドットに適用され、Retina ディスプレイでより鮮明になります。
- 「メニューバーのみ」を選ぶと、設定ウインドウを閉じた後に Dock アイコンが消えることを警告します。
- ポップオーバーのオーディオコントロールとフッターがよりコンパクトになりました。ミュートスイッチはヘッダーに移動し、重複したスピーカーアイコンは削除され、出力デバイス名はサブタイトルになり、「その他の操作」が追加されました。
- ポップオーバーの各行はアイコンサイズと間隔を統一しました。既定のメニューバーアイコンは 24 pt、Wi-Fi シンボルの拡大は既定で 160% です。

## 修正
- アイコンオプションを変更すると、メニューバーと Dock のアイコンが即座に再描画され、遅延しなくなりました。
- 設定のメニューバープレビューがページ上部に固定され、オプションと一緒にスクロールしなくなりました。
- 既知の Wi-Fi ネットワークをクリックすると、システムの Wi-Fi 設定が直接開きます。
- ステータスアイコン内で Wi-Fi シンボルが中央に配置されました（issue #30）。
