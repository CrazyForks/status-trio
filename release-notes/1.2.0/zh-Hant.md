# 版本 %VERSION%（構建 %BUILD%）

## 本次重點：藍牙音訊
- 彈出面板的「藍牙」列現在會顯示即時狀態：已連線裝置的名稱，以及 AirPods 的左右耳與充電盒電量。其他裝置只顯示名稱。
- 透過藍牙播放音訊時，中間的網路圖示可以換成對應的裝置圖示（AirPods、耳機、揚聲器等）並以藍色顯示，音量點或音量弧也會一併變成藍色，一眼就能看出目前使用中的輸出裝置。
- 新增「設定 > 藍牙」頁面：可切換是否替換網路圖示、是否使用藍色藍牙音量、是否讓網路錯誤優先，以及是否顯示藍牙電量，另有 100%–180% 的藍牙圖示大小。
- 修正裝置在「系統設定」中重新命名後仍顯示舊名稱的問題。
- 修正藍牙電量在摘要與裝置頁面之間切換後一直顯示「無法取得」的問題。

## 電池詳細資訊
- 點一下彈出面板中的電池列，會開啟獨立頁面，顯示電源轉接器額定功率、剩餘時間、低耗電模式、電壓、電流、取樣時間與循環次數。
- 新增電池淨功率估算：充電時以綠色標示為「充電（估算）」，放電時顯示「放電（估算）」。
- 這些數值都是盡力而為的估算，並非 Mac 的總耗電量。切換電源後，macOS 最多需要約一分鐘才會回報新數值；這段期間會顯示「取樣中」而不是「無法取得」。

## Wi-Fi 摘要
- 連接 Wi-Fi 時，彈出面板會以網路名稱（SSID）為標題，並在下方顯示目前頻段與訊號強度，例如 5 GHz / -52 dBm。
- 缺少的測量值會直接省略，不會以 0 代替；乙太網路、離線與其他非 Wi-Fi 路徑都不會顯示這些數值。

## 認識你的圖示
- 全新安裝後第一次啟動會開啟「認識你的圖示」指南。選取電池弧、中間的網路圖示或音量指示，即可了解各自的意義；音量說明會跟隨你目前的點或弧設定。
- 指南內含常見狀態組合一覽：充電、低電量、乙太網路、無網際網路並靜音、熱點搭配低耗電模式、弱 Wi-Fi 搭配 25% 音量、Wi-Fi 關閉、藍牙耳機、AirPods，以及 Wi-Fi 搭配藍色音量。
- 更新到這個版本、重新啟動，以及既有安裝都不會自動開啟。你隨時可以從「設定」、「應用程式圖示」、「開啟指南」再次打開。

## 音量
- 新增「自然捲動」開關：開啟後，使用滑鼠或觸控板向上捲動都會提高音量，不受系統「自然捲動」偏好設定影響；關閉時，音量跟隨系統的捲動方向。
- 新增「調整範圍」選項：可在面板任意處捲動，或只在音量控制項上捲動。
- 若開啟後向上捲動仍然降低音量，表示 MOS、Scroll Reverser 或 LinearMouse 等捲動工具正在反轉事件；請在該應用程式中把 Status Trio 加入例外或忽略清單。

## 設定與外觀
- 音量樣式（點或弧）、圖示位置與外環線條粗細改為視覺化卡片選擇器：選取項目會以同心圓環標示，並在卡片中直接預覽結果。
- 新增「外環線條粗細」設定：細、標準或粗，套用於電池外環、音量弧與音量點，在 Retina 顯示器上更清晰。
- 選擇「僅選單列」時會警告：關閉設定視窗後 Dock 圖示會消失。
- 彈出面板的音訊控制項與頁尾更精簡：靜音開關移入標題列、移除重複的揚聲器圖示、輸出裝置名稱改為副標題，並新增「更多動作」項目。
- 彈出面板各列現在共用相同的圖示大小與間距；預設選單列圖示為 24 pt，Wi-Fi 符號縮放預設為 160%。

## 修正
- 變更圖示選項後，選單列與 Dock 圖示會立即重繪，不再延遲一步。
- 設定中的選單列預覽會固定在頁面頂端，不再隨選項捲動。
- 點按已知的 Wi-Fi 網路會直接開啟系統 Wi-Fi 設定。
- Wi-Fi 符號在狀態圖示中置中（issue #30）。
