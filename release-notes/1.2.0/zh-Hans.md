# 版本 %VERSION%（构建 %BUILD%）

## 本次重点：蓝牙音频
- 弹窗「蓝牙」行改为显示实时状态：已连接设备的名称，以及 AirPods 的左右耳与充电盒电量；其他设备只显示名称。
- 通过蓝牙播放时，中间的网络图标可以换成对应的设备图标（AirPods、耳机、音箱等）并显示为蓝色，音量点或音量弧也一并变蓝，一眼看出声音从哪来。
- 新增「设置 › 蓝牙」页面：「替换网络图标」「使用蓝色音量」「网络错误优先」「显示蓝牙电量」四个开关，以及 100%–180% 的蓝牙图标大小。
- 修复设备在「系统设置」里改名后仍显示旧名称的问题。
- 修复在摘要与设备详情之间来回切换时，蓝牙电量长时间显示「不可用」的问题。

## 电量详情
- 点击弹窗中的电量行可进入独立页面，查看适配器额定功率、剩余时间、低电量模式、电压、电流、采样时间与循环次数。
- 新增电池净功率估算：充电时标为绿色「充电（估算）」，放电时标为「放电（估算）」。
- 这些数值均为尽力而为的估算，不是整机功耗；更换电源后 macOS 最多需要约一分钟才会报出新值，此期间显示「采样中…」。

## Wi-Fi 摘要
- 连接 Wi-Fi 时，弹窗以网络名称（SSID）为标题，下方显示当前频段与信号强度，例如「5 GHz · -52 dBm」。
- 缺失的测量值直接省略，不会用 0 代替；以太网、离线等状态下不显示这些数值。

## 图标指南
- 首次安装后第一次启动会打开「认识你的图标」指南，选中电池弧、中心网络或底部音量即可看到对应讲解，音量说明会跟随你当前的点/弧设置。
- 指南内置常见状态组合一览：充电、低电量、以太网、无网络 + 静音、热点 + 低电量模式、弱 Wi-Fi + 25% 音量、Wi-Fi 关闭、蓝牙耳机、AirPods、Wi-Fi + 蓝色音量。
- 更新到本版本、重启或已使用过的安装不会自动弹出，可随时从「设置 › 应用图标 › 打开指南」再次查看。

## 音量调节
- 新增「自然滚动」开关：开启后鼠标与触控板上滚都增大音量，不受系统「自然滚动」偏好影响；关闭时音量跟随系统的滚动方向。
- 新增「调整范围」：可选择整个面板滚动生效，或仅在音量控件上滚动生效。
- 若开启后上滚仍减小音量，说明系统里装有 MOS、Scroll Reverser、LinearMouse 等滚动工具，需要在其中把 Status Trio 设为不处理（加入例外/忽略列表）。

## 设置与外观
- 音量样式（点 / 弧）、图标位置、环形描边粗细改为可视化卡片选择，选中项以同心圆环标出，可直接在卡片中预览效果。
- 新增「环形描边宽度」：细 / 标准 / 粗，同时作用于电池外环、音量弧与音量点，在 Retina 屏幕上更清晰。
- 选择「仅菜单栏」时会提示关闭设置窗口后 Dock 图标将消失。
- 弹窗音频控件与页脚更紧凑：静音开关并入标题，去掉重复的喇叭图标，输出设备名称作为副标题显示，并新增「更多操作」入口。
- 统一弹窗各行的图标尺寸与间距；默认菜单栏图标调整为 24 pt，Wi-Fi 图标缩放默认 160%。

## 更新下载
- 检查更新或下载安装包时，如果 GitHub 直连失败（超时、连接被重置等），会自动切换镜像源重试，依次尝试 gh-proxy.com 与 ghfast.top，网络受限地区无需手动处理。
- 只有直连与镜像全部失败后才会提示错误，中途不再弹出失败提示。
- 镜像只承担传输，安装包仍由 Sparkle 校验签名后才能安装。

## 修复与优化
- 修改图标选项后，菜单栏与 Dock 图标立即重绘，不再延迟一拍。
- 设置窗口中的菜单栏预览固定在页面顶部，滚动选项时不再跟随滚动。
- 点击已知 Wi-Fi 网络可直接打开系统的 Wi-Fi 设置。
- Wi-Fi 符号在状态图标中居中（issue #30）。
