# 버전 %VERSION%(빌드 %BUILD%)

- 오디오 입력 제어를 추가했습니다. 기본 마이크 전환, 입력 음량 조절 및 음소거, 마이크 사용 상태 확인을 지원합니다.
- VPN 상태 항목을 추가하고 현재 활성화된 Ethernet 연결을 표시합니다.
- 메뉴 막대 배터리 아이콘에 충전 코멧 효과를 추가했습니다.
- HID 기능을 바탕으로 키보드, 마우스, 트랙패드, 게임 컨트롤러를 식별하도록 Bluetooth 기기 인식을 개선했습니다. 연결된 기기의 종류를 확인할 수 없는 경우 연결 해제 전에 확인을 요청합니다.
- 유령 Bluetooth 기기나 개별 기기를 숨길 수 있으며, 필요한 경우 권한 안내를 표시합니다.
- 음량 변경 시 사운드 피드백을 개선하고 Dock 아이콘 미리 보기의 메모리 사용량을 줄였습니다.
- 충전 애니메이션을 최적화하고 메뉴 막대 항목을 숨기거나 팝오버를 닫았을 때 백그라운드 모니터링을 줄였습니다.
