# Version %VERSION% (Build %BUILD%)

### New Features

- Added audio input controls to switch the default microphone, adjust or mute input volume, and see when the microphone is in use.
- Added a VPN status item and details for the active Ethernet connection.
- Added a charging comet effect to the menu bar battery icon.

### Improvements & Fixes

- Improved Bluetooth device recognition using HID capabilities to identify keyboards, mice, trackpads, and game controllers. A confirmation is now required before disconnecting a connected device whose type remains unknown.
- Added options to hide ghost Bluetooth devices or individual devices, with a permission prompt when needed.
- Improved the sound feedback when changing the volume and reduced memory use in Dock icon previews.
- Optimized the charging animation and reduced background monitoring when the menu bar item is hidden or the popover is closed.
