# 版本 %VERSION%（構建 %BUILD%）

### 新功能

- 新增音訊輸入控制，可切換預設麥克風、調整輸入音量及靜音，並查看麥克風使用狀態。
- 新增 VPN 狀態項目，顯示目前連線狀態；有線網路狀態現在會顯示目前作用中的連線及詳細資訊。
- 選單列電池圖示新增充電彗星效果。

### 改進與修正

- 改進藍牙裝置識別：結合 HID 能力識別鍵盤、滑鼠、觸控板和遊戲控制器；若仍無法確認已連線裝置的類型，中斷連線前會要求確認。
- 支援隱藏無效藍牙裝置或個別裝置，並在需要時提示藍牙權限。
- 改進調整音量時的聲音回饋。
- 降低 Dock 圖示預覽的記憶體使用量，並最佳化充電動畫效能。
- 選單列項目隱藏或彈出面板關閉時，減少背景監控工作。
