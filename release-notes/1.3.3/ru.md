# Версия %VERSION% (сборка %BUILD%)

- Добавлены элементы управления аудиовходом: выбор микрофона по умолчанию, настройка или отключение звука входа и отображение активности микрофона.
- Добавлен индикатор VPN и отображение активного подключения Ethernet.
- Для значка батареи в строке меню добавлен эффект кометы во время зарядки.
- Улучшено распознавание Bluetooth-устройств по возможностям HID: клавиатур, мышей, трекпадов и игровых контроллеров. Перед отключением подключённого устройства, тип которого определить не удалось, теперь требуется подтверждение.
- Можно скрывать несуществующие Bluetooth-устройства или отдельные устройства; при необходимости отображается запрос разрешения.
- Улучшена звуковая обратная связь при изменении громкости и снижено потребление памяти при предварительном просмотре значка Dock.
- Оптимизирована анимация зарядки и снижена фоновая активность, когда элемент строки меню скрыт или всплывающая панель закрыта.
