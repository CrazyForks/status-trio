# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 新增音频输入控制，可切换默认麦克风、调节输入音量和静音，并查看麦克风使用状态。
- 新增 VPN 状态项，显示当前连接状态；有线网络状态现在会显示当前活动链路及连接信息。
- 菜单栏电池图标新增充电彗星效果。

### 改进与修复

- 改进蓝牙设备识别：结合 HID 能力识别键盘、鼠标、触控板和游戏控制器；对仍无法确定类型的已连接设备，断开前会要求确认。
- 支持隐藏无效蓝牙设备或单个设备，并在需要时提示蓝牙权限。
- 优化调节音量时的声音反馈。
- 降低程序坞图标预览的内存占用，优化充电动画性能。
- 减少菜单栏项目隐藏或弹出面板关闭时的后台监控工作。
