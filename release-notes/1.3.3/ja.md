# バージョン %VERSION%（ビルド %BUILD%）

- オーディオ入力コントロールを追加しました。デフォルトのマイクの切り替え、入力音量の調整やミュート、マイクの使用状況の確認ができます。
- VPN の接続状態項目を追加し、現在アクティブな Ethernet 接続を表示します。
- メニューバーのバッテリーアイコンに充電中のコメット効果を追加しました。
- HID 機能を使った Bluetooth デバイスの識別を改善し、キーボード、マウス、トラックパッド、ゲームコントローラーをより正確に判別します。種類を特定できない接続中のデバイスを切断する際は、確認を求めるようになりました。
- 不正な Bluetooth デバイスや個別のデバイスを非表示にできるようになりました。必要に応じて Bluetooth のアクセス許可を案内します。
- 音量変更時のサウンドフィードバックを改善し、Dock アイコンのプレビューで使用するメモリを削減しました。
- 充電アニメーションを最適化し、メニューバー項目を非表示にしたときやポップオーバーを閉じたときのバックグラウンド監視を減らしました。
