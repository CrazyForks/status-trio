# Version %VERSION% (Build %BUILD%)

- Neue Steuerelemente für Audioeingaben: Standardmikrofon auswählen, Eingangslautstärke anpassen und stummschalten sowie die Mikrofonaktivität anzeigen.
- Ein VPN-Status zeigt die Verbindung an. Für Ethernet wird die aktive kabelgebundene Verbindung angezeigt.
- Das Batteriesymbol in der Menüleiste erhält einen Kometeneffekt beim Laden.
- Bluetooth-Geräte werden anhand ihrer HID-Funktionen besser erkannt, darunter Tastaturen, Mäuse, Trackpads und Gamecontroller. Vor dem Trennen eines verbundenen Geräts mit weiterhin unbekanntem Typ wird eine Bestätigung verlangt.
- Ungültige Bluetooth-Geräte oder einzelne Geräte lassen sich ausblenden; bei Bedarf wird auf fehlende Bluetooth-Berechtigungen hingewiesen.
- Die Klangrückmeldung beim Ändern der Lautstärke wurde verbessert und der Speicherbedarf der Dock-Symbolvorschauen reduziert.
- Die Ladeanimation wurde optimiert. Bei ausgeblendeten Menüleistenelementen oder geschlossenen Popover-Fenstern wird die Hintergrundüberwachung reduziert.
