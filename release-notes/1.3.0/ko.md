# 버전 %VERSION%(빌드 %BUILD%)

## macOS 26의 네이티브 Liquid Glass 모습
- 팝오버가 macOS 26의 Liquid Glass 재질을 사용하므로 시스템 메뉴와 어울리고, 투명도 줄이기 같은 설정도 그대로 적용됩니다.
- macOS 15~25는 기존 모양을 그대로 유지합니다. 최소 시스템 버전은 그대로이므로 Status Trio를 계속 쓰기 위해 macOS를 업데이트할 필요가 없습니다.

## Bluetooth가 더 잘 동작합니다
- 상태 패널이 이제 페어링된 기기를 바로 나열합니다. 기기를 탭하면 연결되고, 한 번 더 탭하면 연결이 해제됩니다. 키보드나 마우스의 연결 해제는 먼저 해당 행에서 확인을 요청합니다.
- 설정에서 기기를 드래그하여 순서를 정할 수 있으며, 연결된 기기가 항상 먼저 표시됩니다.
- Bluetooth 배터리 잔량이 이제 기본으로 표시되며, 켜 둘 스위치가 필요 없습니다.

## Wi-Fi 전환은 시스템 설정에서 이루어집니다
- 앱이 더 이상 네트워크에 직접 연결하지 않습니다. 네트워크를 선택하면 시스템 설정의 Wi-Fi 패널이 열리고, 거기서 직접 전환합니다.
- Status Trio는 더 이상 Wi-Fi 암호를 읽거나 저장하지 않습니다.
- 이전 버전이 저장한 암호 항목이 키체인에 남아 있을 수 있지만 더 이상 사용되지 않습니다.
- 네트워크 보기, 신호 세부 정보, Wi-Fi 스위치는 모두 이전과 같이 동작합니다.

## 전력 소모가 줄었습니다
- 백그라운드 작업이 크게 줄었습니다. Bluetooth가 더 이상 타이머로 기기를 폴링하지 않고, Wi-Fi 페이지를 닫으면 검색이 멈추며, 폴백 새로 고침이 5초마다에서 15초마다로 늘어났습니다.
- 시스템이 변경을 보고하면 여전히 즉시 업데이트되며, 상태 새로 고침 간격 설정은 그대로입니다.

## 수정 및 개선 사항
- 다른 앱이 전체 화면일 때도 메뉴 막대 아이콘을 클릭하면 패널이 열립니다.
- 배터리 세부 정보의 전력 수치가 더 정확해졌습니다. 전원을 쓸 때는 **시스템 소비 전력(추정)**, 배터리를 쓸 때는 **배터리 방전 전력(추정)**으로 표시됩니다.
- 이전에 Wi-Fi에 대해 거부한 위치 권한은 다시 요청할 수 있으며, 더 이상 네트워크 이름을 사용할 수 없음 상태에 멈춰 있지 않습니다.
- 시스템의 동작 줄이기를 켠 경우 설정 화면이 전환 애니메이션을 더 이상 재생하지 않습니다.
