# 버전 %VERSION%(빌드 %BUILD%)

## macOS 26 이상의 네이티브 Liquid Glass
- 팝오버가 이전 macOS에서 이어져 온 흐린 유리 느낌 대신 시스템 자체의 Liquid Glass 재질을 사용하므로 주변 메뉴와 패널과 어울립니다.
- 앱만의 스타일이 아니라 시스템 모양입니다. 시스템 설정을 따릅니다.
- macOS 15~25는 기존 모양을 그대로 유지합니다. 최소 시스템 버전은 그대로이므로 Status Trio를 계속 쓰기 위해 macOS를 업데이트할 필요가 없습니다.

## 다른 앱이 전체 화면일 때도 패널이 열립니다
- 다른 앱이 전체 화면일 때 메뉴 막대 아이콘을 클릭하면 상태 패널이 열립니다. 이전에는 그 앱 뒤에 열려서 클릭해도 아무 반응이 없는 것처럼 보였습니다.

## 백그라운드 새로 고침이 가벼워졌습니다
- 폴백 새로 고침(시스템이 앱에 전달하지 않은 변경을 잡아내는 타이머)은 기본값이 5초에서 15초로 바뀌었고, macOS가 이 타이머를 다른 작업과 함께 실행되도록 미룰 수 있습니다. 시스템이 변경을 보고하면 아이콘은 여전히 즉시 업데이트됩니다.
- 배터리는 폴백 새로 고침마다 확인합니다. 상태 패널과 설정 윈도우가 모두 닫혀 있는 동안에는 Wi-Fi와 볼륨을 더 드물게 확인하고, 둘 중 하나라도 화면에 나타나면 곧바로 설정한 상태 새로 고침 간격으로 돌아갑니다.
- 상태 새로 고침 간격 슬라이더는 예전 주기를 원하는 경우에도 여전히 5초까지 내릴 수 있습니다.
- 볼륨 행은 볼륨 값이 바뀌지 않았을 때 상태 패널을 다시 그리지 않습니다.

## Bluetooth는 더 이상 백그라운드에서 폴링하지 않습니다
- Bluetooth 패널은 앱이 실행되는 동안 계속 15초마다 페어링된 기기 목록을 읽었으며, 패널을 닫은 뒤에도 마찬가지였습니다. 이제는 기기가 연결되거나 연결 해제될 때 새로 고치고, 화면에 Bluetooth 보기가 있을 때만 느린 확인으로 되돌아갑니다.
- 페어링된 기기와 배터리 잔량은 이제 두 개가 아닌 하나의 시스템 보고서에서 가져오므로, 새로 고침마다 하는 작업이 절반으로 줄었습니다.
- 요약 행과 기기 페이지는 달라지지 않았습니다. 같은 이름, 같은 잔량, 같은 권한 동작이며, Bluetooth 권한은 Bluetooth 보기를 열 때만 요청합니다.

## Wi-Fi 페이지를 닫으면 검색이 멈춥니다
- Wi-Fi 페이지는 이전에는 열려 있는 동안 약 5초마다 모든 채널을 검사했고, 요약으로 돌아간 뒤에도 계속했습니다. 이제는 페이지를 열 때, 새로 고침을 클릭할 때, Wi-Fi 스위치를 전환할 때 검색하고, 그 사이에는 마지막 결과를 유지합니다.
- Wi-Fi 페이지를 닫으면 검색 루프가 백그라운드에서 계속 실행되지 않고 멈춥니다.
- Wi-Fi 인터페이스가 없는 Mac(예: 유선 네트워크를 쓰는 Mac mini 또는 Mac Studio)에서는 앱이 더 이상 30초마다 Wi-Fi 모니터링을 다시 만들지 않고, 몇 번 시도한 뒤 깨어남이나 네트워크 변경을 기다립니다.
- 목록 자체는 달라지지 않았습니다. 같은 네트워크, 같은 세부 정보, 같은 수동 새로 고침 버튼입니다.

## Wi-Fi 전환은 시스템 설정에서 이루어집니다
- 팝오버는 더 이상 네트워크에 연결하거나 네트워크 간을 전환하지 않습니다. 네트워크를 선택하면 시스템 설정의 Wi-Fi 패널이 열리며, Wi-Fi 페이지에서도 이를 여는 버튼 위에 그렇게 안내합니다.
- Status Trio는 더 이상 Wi-Fi 암호를 읽거나 저장하지 않습니다. 이전 동작은 믿을 수 있게 만들 수 없었습니다. macOS는 저장된 네트워크의 암호를 자체적으로 보관하며, 오래된 저장 사본은 연결 실패와 키체인 허용 요청의 반복으로 이어졌고, 암호가 잘못되었다는 사실을 알려 줄 방법도 없었습니다.
- 이전 버전에서 **키체인에 암호 저장**을 선택했다면 그 키체인 항목은 그대로 남아 있지만 더 이상 사용되지 않습니다. 키체인 접근에서 `com.lingsmbp.StatusTrio.wifi-password`를 검색해 삭제할 수 있습니다.
- 페이지의 나머지 부분은 달라지지 않았습니다. 같은 네트워크, 같은 신호 세기와 링크 세부 정보, 같은 Wi-Fi 스위치, 그리고 시스템 설정을 여는 버튼도 그대로입니다.
