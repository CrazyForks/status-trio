# 版本 %VERSION%（構建 %BUILD%）

## macOS 26 及以上的原生 Liquid Glass
- 彈出面板改用系統自帶的 Liquid Glass 材質，不再沿用舊版 macOS 的磨砂觀感，與周圍的選單和面板保持一致。
- 這是系統外觀而非 app 自訂樣式：它跟隨系統設定，包括「降低透明度」與系統的玻璃色調。
- macOS 15–25 的觀感保持不變；最低系統版本未變，使用者無需升級 macOS 即可繼續使用 Status Trio。

## 其他 App 全螢幕時正常彈出面板
- 其他 App 處於全螢幕時，點擊選單列圖示現在會正常彈出狀態面板；此前彈出面板會開在該 App 後面，看起來像沒有反應。
