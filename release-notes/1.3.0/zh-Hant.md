# 版本 %VERSION%（構建 %BUILD%）

## macOS 26 的原生玻璃外觀
- 彈出面板改用 macOS 26 的 Liquid Glass 材質，和系統選單渾然一體；「降低透明度」等系統設定照常生效。
- macOS 15–25 外觀不變，系統要求也不變，無需升級就能繼續用。

## 藍牙更好用了
- 狀態面板直接列出已配對裝置：點一下連接，再點一下中斷連接；中斷鍵盤、滑鼠會先在列內跟你確認。
- 在設定裡拖動裝置即可調整順序，已連接的始終排最前。
- 藍牙電量預設顯示，不用再手動打開。

## 切換 Wi-Fi 交給系統
- App 不再幫你加入網路：點任意網路會打開系統的 Wi-Fi 設定，在那裡切換。
- Status Trio 從此不讀取、不儲存 Wi-Fi 密碼。
- 舊版本留下的密碼項目仍在鑰匙圈裡，但已不再使用。
- 看網路、看訊號、Wi-Fi 開關都和以前一樣。

## 更省電
- 背景活動大幅減少：藍牙不再定時輪詢裝置，離開 Wi-Fi 頁面就停止掃描，備援重新整理也從每 5 秒放寬到每 15 秒。
- 該更新時照樣立刻更新：系統一報告變化，圖示馬上回應；重新整理間隔設定保持原樣。

## 修正與改善
- 其他 App 全螢幕時，點選單列圖示現在能正常彈出面板。
- 電池詳情的功率讀數更準：接電顯示「系統功耗（估算）」，拔電顯示「電池放電（估算）」。
- Wi-Fi 定位授權被拒後可以重新發起，不再卡在「無法顯示網路名稱」。
- 系統開啟「減少動態效果」後，設定介面也不再播放過渡動畫。
