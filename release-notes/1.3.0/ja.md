# バージョン %VERSION%（ビルド %BUILD%）

## macOS 26 のネイティブ Liquid Glass の見た目
- ポップオーバーは macOS 26 の Liquid Glass 素材を使い、システムのメニューやパネルと調和します。透明度を下げるなどの設定はこれまでどおり適用されます。
- macOS 15〜25 の見た目は変わりません。最低システムバージョンは変わらないため、Status Trio を使い続けるために macOS をアップグレードする必要はありません。

## Bluetooth の動作が改善
- ステータスパネルはペアリング済みデバイスをすぐに一覧表示します。タップすると接続し、もう一度タップすると切断します。キーボードやマウスを切断するときは、先にその行内で確認を求めます。
- 設定でデバイスをドラッグして並べ替えられます。接続中のデバイスは常に先頭に表示されます。
- Bluetooth のバッテリー残量はデフォルトで表示され、オンにするスイッチは必要ありません。

## Wi-Fi の切り替えはシステム設定で行います
- アプリはネットワークに接続しなくなりました。ネットワークをタップするとシステム設定の Wi-Fi 設定が開き、切り替えはそこで行います。
- Status Trio は Wi-Fi パスワードを読み取ることも保存することもなくなりました。
- 以前のバージョンで保存したパスワードの項目がキーチェーンに残っている場合がありますが、もう使われることはありません。
- ネットワーク、電波の詳細、Wi-Fi スイッチはすべてこれまでどおり動作します。

## 消費電力の削減
- バックグラウンドの処理が大幅に減りました。Bluetooth はタイマーでデバイスをポーリングしなくなり、Wi-Fi スキャンはページを離れると停止し、フォールバック更新の間隔は 5 秒ごとから 15 秒ごとに延びました。
- システムから変更が通知されたときはこれまでどおりすぐに更新され、ステータス更新間隔の設定も変わりません。

## 修正と改善
- 他のアプリがフルスクリーンのときでも、メニューバーのアイコンをクリックするとステータスパネルが開くようになりました。
- バッテリーの詳細の消費電力の値がより正確になりました。電源接続時は「システム消費電力（推定）」、バッテリー駆動時は「バッテリー放電電力（推定）」を表示します。
- Wi-Fi で拒否した位置情報の許可を、もう一度リクエストできるようになりました。ネットワーク名が表示できない状態のままになることはありません。
- システムの「モーションの軽減」をオンにしているとき、設定画面でもうトランジションアニメーションを再生しません。
