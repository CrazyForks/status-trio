# Version %VERSION% (Build %BUILD%)

- Neuer Abschnitt „In der Nähe“ im Bluetooth-Bereich (standardmäßig aus): liest den Akkustand von iPhone und iPad.
- AirPods können jetzt den Hörmodus wechseln.
- Die Lautstärke externer Displays lässt sich jetzt einstellen.
- Das Menüleisten-Symbol kann das Symbol eines gewählten Bluetooth-Geräts statt des WLAN-Symbols zeigen.
- Neue Option „Batterieprozentsatz an der Verbindungsposition anzeigen“.
- Neue Option „Ladeblitz-Puls“: Bei eingeschaltetem Ladeeffekt pulsiert der Blitz mit.
- AirPods 5 wird erkannt.
- Geräte mit mehrteiligen Akkuständen, etwa AirPods (links / rechts / Ladecase), nutzen jetzt eine zweite Zeile; der Gerätename wird nicht mehr verdrängt.
- iPhone und iPad haben unterschiedliche Symbole.
- Das WLAN-Symbol ist bei größerer Darstellung wieder zentriert (#30).
- Auf manchen Geräten (z. B. einigen BenQ-Displays) wurde keine Lautstärke angezeigt — behoben.
- Die Lautstärke externer Displays wird nur auf Apple Silicon unterstützt.
