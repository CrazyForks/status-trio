# バージョン %VERSION%（ビルド %BUILD%）

- Bluetooth パネルに「近くのデバイス」セクションを追加（初期設定ではオフ）：オンにすると iPhone と iPad のバッテリー残量を読み取れます。
- AirPods のヒアリングモードを切り替えられるようになりました。
- 外付けディスプレイの音量を調整できるようになりました。
- メニューバーのアイコンに、Wi-Fi アイコンの代わりに任意の Bluetooth デバイスのアイコンを使えます。
- 「接続位置にバッテリー残量を表示」を追加しました。
- 「充電ボルトの鼓動」を追加しました。充電エフェクトをオンにすると、ボルトも鼓動します。
- AirPods 5 を識別できるようになりました。
- AirPods など左右やケースの残量を持つデバイスは、デバイス名を圧迫しないよう 2 行目に表示されます。
- iPhone と iPad のアイコンを分けました。
- Wi-Fi アイコンを拡大したときに中央にそろわない問題を修正しました（#30）。
- 一部のデバイス（BenQ の一部ディスプレイなど）で音量が空になる問題を修正しました。
- 外付けディスプレイの音量は Apple Silicon のみの対応です。
