# Version %VERSION% (Build %BUILD%)

### New Features

- The Bluetooth panel has a new "Nearby" section (off by default): turn it on to read iPhone and iPad battery levels.
- AirPods can now switch listening modes.
- External displays can now have their volume adjusted.
- The menu bar icon can use a chosen Bluetooth device's icon in place of the Wi-Fi icon.
- New "Show battery percentage in the connection position" switch.
- New "Charging bolt pulse" switch: with the charging effect on, the bolt pulses along with it.

### Improvements & Fixes

- AirPods 5 is now identified.
- Devices with multi-part battery levels, AirPods and others (left / right / case), now use a second line, so the device name is no longer squeezed by them.
- iPhone and iPad now use different icons.
- Fixed the Wi-Fi icon not being centered at larger sizes (#30).
- Fixed volume showing as unavailable on some devices (such as some BenQ displays).

### Notes

- Display volume is supported on Apple Silicon only.
