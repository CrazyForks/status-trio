# 版本 %VERSION%（構建 %BUILD%）

### 新功能

- 藍牙面板新增「附近裝置」分組（預設關閉）：開啟後可以讀取到 iPhone、iPad 電量。
- AirPods 現在支援切換聆聽模式。
- 外接顯示器現在可以調整音量。
- 選單列圖示可以指定用某個藍牙裝置的圖示取代 Wi-Fi 圖示。
- 新增「在連線位置顯示電量數字」開關。
- 新增「閃電脈動」開關：開啟後，充電時閃電也會跟著心跳（需先開啟充電動畫）。

### 改進與修正

- 辨識 AirPods 5。
- AirPods 等支援多組件電量的裝置（左 / 右 / 充電盒）改到第二行，裝置名稱不再被電量擠掉。
- iPhone 和 iPad 的圖示區分開了。
- 修好 Wi-Fi 圖示放大後未置中（#30）。
- 修好部分裝置音量顯示為空（如某些 BenQ 顯示器）。

### 說明

- 外接顯示器音量目前只在 Apple Silicon 上支援。
