# Версия %VERSION% (сборка %BUILD%)

- Новый раздел «Рядом» в панели Bluetooth (по умолчанию выключен): читает заряд iPhone и iPad.
- AirPods теперь могут переключать режим прослушивания.
- Теперь можно регулировать громкость внешних дисплеев.
- Значок в строке меню может использовать значок выбранного устройства Bluetooth вместо значка Wi-Fi.
- Новая настройка «Показывать процент заряда на месте подключения».
- Новая настройка «Пульсация молнии зарядки»: при включённом эффекте зарядки молния тоже пульсирует.
- AirPods 5 теперь определяется.
- Устройства с зарядом по компонентам, например AirPods (левый / правый / чехол), показывают их во второй строке и больше не мешают названию устройства.
- У iPhone и iPad теперь разные значки.
- Исправлено смещение значка Wi-Fi при увеличении (#30).
- Исправлено пустое значение громкости на некоторых устройствах (например, на части дисплеев BenQ).
- Громкость внешних дисплеев поддерживается только на Apple Silicon.
