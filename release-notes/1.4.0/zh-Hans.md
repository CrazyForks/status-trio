# 版本 %VERSION%（构建 %BUILD%）

### 新功能

- 蓝牙面板新增「附近设备」分组（默认关闭）：开启后可以读取到 iPhone、iPad 电量。
- AirPods 现在支持切换聆听模式。
- 外接显示器现在可以调音量。
- 菜单栏图标可以指定用某个蓝牙设备图标替代 Wi-Fi 图标。
- 新增「在连接位置显示电量数字」开关。
- 新增「闪电心跳」开关：开启后，充电时闪电也会跟着心跳（需先开启充电动画）。

### 改进与修复

- 识别 AirPods 5。
- AirPods 等支持多组件电量的设备（左 / 右 / 充电盒）改到第二行，设备名不再被电量挤掉。
- iPhone 和 iPad 的图标区分开了。
- 修好 Wi-Fi 图标放大后不居中（#30）。
- 修好部分设备音量显示为空（如某些 BenQ 显示器）。

### 说明

- 外接显示器音量目前只在 Apple Silicon 上支持。
